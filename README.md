# PhraseBoard
A simple clipboard app for easy phrase storage and access.

## Description
PhraseBoard is a simple application that allows you to create and store phrases for easy copy and paste. You can add new phrases, pin them to the top of the window, and resize the window to fit your needs. The application also tracks the last active window and pastes the phrases there.

## Getting Started
Follow these steps to get a local copy up and running.

### Prerequisites
Python and Tkinter are required to run this project.
Tkinter is a standard Python library for creating graphical user interfaces.

### Installation
1. Clone the repo
   ```sh
   git clone https://github.com/JerryCarry101/PhraseBoard.git
   ```

## Usage
To use this project, run the following command:
```sh
python PhraseBoard.py
```

## Features
- Create Phrases for easy access
- Pin Phrases to the top of the window
- Resize the window to fit your needs
- Track the last active window and paste the phrase there
- Add new phrases with a simple button click

## Requirements
- Python 3.8 or higher
- Tkinter library
